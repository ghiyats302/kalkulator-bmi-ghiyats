# ⚖️ Aplikasi Kalkulator BMI (Body Mass Index)

Aplikasi desktop berbasis **Java Swing (GUI)** untuk menghitung indeks massa tubuh (*Body Mass Index* / BMI) berdasarkan input tinggi dan berat badan pengguna. Proyek ini dibuat menggunakan Apache NetBeans dengan struktur proyek **Java Maven**[cite: 1, 2].

## ✨ Fitur Utama
- **Perhitungan BMI Otomatis:** Menghitung nilai BMI secara akurat dari input tinggi dan berat badan.
- **Tabel Referensi Terintegrasi:** Dilengkapi dengan komponen *Tabbed Pane* yang memuat:
  - **BMI Tabel:** Kategori standar (Normal, Overweight, Obesity Level 1–3)[cite: 2].
  - **BMI Table NCI:** Referensi rentang BMI berdasarkan kelompok usia (Age).
- **Kontrol Interaktif:** Tombol **Hitung BMI**, **Reset** untuk mengosongkan form, dan **Exit** untuk menutup aplikasi[cite: 2].

## 🛠️ Teknologi yang Digunakan
- **Bahasa Pemrograman:** Java
- **Framework GUI:** Java Swing (`JFrame`, `JTabbedPane`, `JTable`, `JTextField`)[cite: 2]
- **Build Tool:** Apache Maven
- **IDE:** Apache NetBeans
